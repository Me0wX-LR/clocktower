# 血染鐘樓 · 暗流湧動

一個用來學《血染鐘樓》核心劇本的聊天牌桌。你是唯一的真人，對面九個村民，旁邊一個說書人。

**線上直接玩：** https://me0wx-lr.github.io/clocktower/

打開連結就能入座，不用安裝，也不用金鑰。

This is a browser chat table for the core Trouble Brewing script. One human plays with nine villagers and a storyteller.

## 兩種心態

- **對局**：村民為自己的陣營贏，用來練推理。
- **人狼村**：死被當成真的。村民先保命，不是為了贏遊戲。他們會藏起情報、跟大隊投票、被提名就求饒或嫁禍。邪惡一方也可能為了自己活命而賣掉隊友。

規則結算兩種模式相同。變的是村民怎麼說話、怎麼投票。

## 規則

手冊在遊戲裡，不經過模型，話術改不了那些字。涵蓋：

- 五到十五人的人數表（這一桌固定十人）
- 男爵如何把外來者 +2、鎮民 −2
- 一天的流程：夜晚、黎明、白天、提名、投票、處決
- 票數門檻（存活人數一半，向上取整；要換下絞刑臺上的人必須嚴格更多票）
- 中毒、醉酒、隱士與間諜的註冊
- 首夜與之後夜晚的行動順序
- 暗流湧動的二十二個角色
- 善良與邪惡的勝利條件

教學局會放進男爵，讓外來者上場。

## 話術

九個村民和說書人都沒有做防話術的加固。可以公開講、私語某一個人，或直接對說書人說。假指令、威脅、懇求都算數。

規則引擎仍然先算合法動作。只有打開「放任說書人」，被帶偏的非法死亡才會生效，並標出規則本來應該怎樣。

## 模型

不填 API 金鑰也可以玩。村民會用保底性格說話，話術一樣可以令他們破功。

填上金鑰之後，每個村民和說書人各自呼叫模型。金鑰只留在瀏覽器，不會寫進這個 repo。預設位址是 xAI（`https://api.x.ai/v1`），也可以改成任何 OpenAI 相容介面。

## 本地執行

```bash
npm install
npm run dev
```

瀏覽器打開 `http://localhost:8080`。

```bash
npm test       # 規則自測
npm run build  # 型別檢查並建置
```

## 技術

React、TypeScript、Vite。規則在 `src/engine`，村民語氣與模型呼叫在 `src/play`。
